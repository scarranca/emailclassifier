# Cove

## Register
product

## Platform
macOS — native SwiftUI

## Purpose
A personal Gmail client with Jev-powered organization and a local database.

## References
The five user-supplied Cove images define the product direction: a three-column inbox, contextual assistant, weekly calendar, Gmail onboarding, and editable agent preferences.

## Implementation principles
Keep mail readable and actions explicit. Persist work locally. Separate sample data from connected accounts. Distinguish Jev decisions and source excerpts from generated text. Sending is always a user action.
