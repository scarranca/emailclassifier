Quieter reviews, more reliable deletion

  • Uncertain agent results now stay in Agents → Activity without adding a Gmail label. A Needs review filter makes them easier to find. Existing review labels are left unchanged.
  • Clearly unrelated email no longer becomes a review solely because an attachment could not be read. Uncertain or incomplete matches still require review before an agent acts.
  • ⌘Delete can queue emails while Cove is busy. The notification distinguishes waiting from an active Gmail request, and Undo remains available until the request starts.
  • Deleting another email while a previous deletion is being sent keeps a separate undo window. Long waits restore the affected emails with an error instead of leaving a stuck notification.
